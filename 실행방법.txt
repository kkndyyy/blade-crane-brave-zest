Hellforge (Yupgoolg D2R editor) - run on your PC
================================================

1) Install Node.js LTS from https://nodejs.org  (check Add to PATH)

2) Unzip hellforge-editor.zip to a folder.

3) Double-click run.bat  (English filename - do not use 실행.bat if it errors)

4) Browser opens http://127.0.0.1:8080
   Use Sample, MPQ Open, or drag-drop an .mpq file.

Keep the black window open. Do not Run as Administrator.

Update later: double-click GET-LATEST.bat (or update.bat) in the same folder.

After saving an MPQ:
- Replace the file your D2R shortcut actually loads
  (example: -mod yupgoolg  ->  mods\yupgoolg\yupgoolg.mpq).
- Shortcut target must include  -mod <name> -txt
  Latest Yupgoolg packs ship excel .bin files. Hellforge strips the matching
  .bin on save; without -txt the game keeps the old compiled tables.
- If drops still look old, delete the mod cache under
  Saved Games\Diablo II Resurrected  and launch again.
